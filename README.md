# Calculadora Médica

Calculadora para cuidados críticos: drogas vasoactivas, sedación, equilibrio ácido-base, ventilación mecánica y otros cálculos clínicos.

## Uso

Abrí `index.html` en cualquier navegador, o entrá a la versión publicada en GitHub Pages (link abajo, una vez activado).

⚠️ Herramienta de apoyo al cálculo. No reemplaza el criterio clínico ni protocolos institucionales — verificar siempre los resultados antes de aplicarlos.
